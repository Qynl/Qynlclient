# Qyn-L Clean BedWars — Minecraft 1.21.1

Original, clean modern PvP textures with a Bare-Bones-inspired minimal style. Vanilla assets remain as a compatibility fallback; BedWars assets are custom-generated by scripts/gen-qynl-packs.mjs.

## BedWars focus
- readable team wool and terracotta with subtle weave/depth
- low-clutter glass with visible edges
- clean red bed and TNT accents
- modernized tools, bows, HUD and container UI
- version-correct asset paths and pack metadata

## Install
Copy this folder into the resourcepacks directory of Minecraft 1.21.1.

## Regenerate
    bun scripts/gen-qynl-packs.mjs
